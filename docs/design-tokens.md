## 2. 타이포그래피 (Pretendard)

> **핵심**: Figma 디자인의 최대 굵기는 **SemiBold(600)**. 이름이 "Bold"인 스타일도 실제 weight는 600입니다. (현재 빌드는 700까지 사용 → 정렬 시 조정 필요)

| 스타일명 | size | weight | line-height | 용도 |
|---|---|---|---|---|
| Heading 2 / Bold | 20 | 600 | 1.40 | 카드 핵심 수치(요약 값) |
| Headline 1 / Bold | 18 | 600 | 1.45 | 카드 제목 |
| Body 2 / Medium·Bold | 15 | 500 / 600 | 1.47 | 강조 본문, 수수료 값 |
| Label 1 / Regular·Medium·Bold | 14 | 400 / 500 / 600 | 1.43 | 표 값, 본문 |
| Label 2 / Regular·Bold | 13 | 400 / 600 | 1.39 | 캡션, 스탬프, AI 본문 |
| Caption 1 / Regular·Medium·Bold | 12 | 400 / 500 / 600 | 1.33 | 표 보조 캡션, 라벨 |

weight 3단계만 사용: **600(SemiBold) / 500(Medium) / 400(Regular)**.

## 4. 공통 컴포넌트 스펙

구조·치수는 Figma 프레임 좌표에서 역산했습니다. (카드 콘텐츠 폭 1008, 좌우 패딩 20)

### 4-1. 카드 컨테이너
- 배경 `Surface/Normal #FFFFFF`, radius **md 8**, 내부 패딩 **20px**, 그림자 `Shadow/Normal`

### 4-2. 카드 헤더 (높이 68)
- **제목**: Headline 1 (18/600), 색 `Label/Neutral`
- **ⓘ 도움말 아이콘**: 20px, hover 시 툴팁
- **우측 액션 버튼**: Solid 버튼(아래), 우측 정렬
- **스탬프**: 제목 아래, Label 2 Regular (13/400), 색 `Label/Alternative` (예: "오늘 06:00 기준")

### 4-3. Solid 버튼 (`Button/Solid`)
- 높이 **36**, 배경 `Surface/Strong #202020`, 글자 `White`, radius sm 6
- 좌측 아이콘(선택) + 라벨 (예: `+ 데이터 연동`)
- 보조 버튼: 높이 24~32 (예: `정산 내역 확인`, `데이터 연동하기`)

### 4-4. 도움말 툴팁 (`Tooltip`, 310×70)
- 제목 + 본문(Label 2), 다크 배경, 헤더 ⓘ에 연결

### 4-5. 연동 서비스 칩 (`item`, 높이 32)
- 아이콘 12 + 라벨 + **상태 표시**: 연동됨 `✓`, 미연동 `+`
- 예: 여신금융협회 ✓ / 배달의민족 ✓ / 쿠팡이츠 +

### 4-6. 요약 서브카드 (328×120, 내부 패딩 20)
- 라벨 Label 2 (13) → 값 Heading 2 (20/600) → 캡션 Label 2 (13)
- 값 색상: 정보=`Blue`, 기본=`Label/Normal`, 입금=`Green`
- **잠금 변형**: 미연동 시 값 위에 "데이터 연동 후 확인" 오버레이 + 연동 버튼

### 4-7. 경고 배너 (`warning`, 높이 48)
- info 뱃지 20 + 문구(Label 1) + 우측 보조 버튼, 배경 `Orange`/`Red` 계열 옅게

### 4-8. 데이터 행 (`item`, 높이 74) — 표형 카드 공통
- **타입 배지** (41×20): `카드` / `배달`
- 셀 구조: **값(Label 1, 14/600) + 캡션(Caption 1, 12/400)** 2줄
- 컬럼: [타입] [명칭+날짜] [결제액] [수수료(+%)] [입금예정]

### 4-9. AI 어드바이스 푸터 (`ai-advice`, 높이 48) — **전 카드 공통**
- AI 아이콘 + "AI 어드바이스" 라벨 + 본문(Label 2, 13/400)
- 전 카드 하단에 동일 패턴으로 반복

## 5. 현재 빌드(index.html)와의 주요 차이 — 정렬 시 반영할 것

| 항목 | 현재 빌드 | Figma | 조치 |
|---|---|---|---|
| 최대 폰트 굵기 | 700 | **600** | 제목/값 weight 600으로 |
| 카드 radius | 6 | **8** | `--radius` 8로 |
| 카드 그림자 | none | **Shadow/Normal** | 옅은 그림자 추가 |
| 라인 색 | `rgba(41,41,41,.15)` | **@10%** | `--line` 10%로 |
| Green | `#119a56` | **`#13AF61`** | 토큰 교체 |
| Blue | `#007cff` | `#007CFF` | 동일 ✓ |
| Orange | `#FF5A0A` | `#FF5A0A` | 동일 ✓ |
| 자간 | 전역 -3% | 스타일별(헤드라인 음수, 본문 양수) | 추후 스타일별 검토 |

> ⚠️ Figma의 정확한 컴포넌트별 채움색·패딩 매핑은 `get_design_context`(일시적으로 분류기 막힘)로 추후 보강 예정.
